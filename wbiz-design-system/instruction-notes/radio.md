## When to use
Choosing exactly one of 2–5 options that should all be visible (Customer Type: Individual / Business).

## When not to use
More than 5 options → `Select`. A single on/off choice → `Checkbox` (a lone radio can't be turned off).

## How it behaves
Options sit side by side. Arrow keys move the choice. If the choice changes which fields apply, show or hide them immediately below.
