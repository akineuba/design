## When to use
At the top of every screen, above the page content.

## How it behaves
- **Left:** breadcrumb. One level ("Dashboard") or Module / Page (/ Record). The current page is blue; earlier levels are links.
- **Right, in this order:** Tour (starts the guided tour for this page) → theme toggle → notifications (red count badge, "99+" above 99) → user (blue avatar, name, role, chevron menu) → app launcher (grid).
- Each control appears only when it is wired up; don't show dead buttons.
- The bar doesn't scroll with the page content.
