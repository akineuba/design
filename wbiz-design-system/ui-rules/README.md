# UI Rules

`ui-rules.md` is the single list of **platform-wide rules** for building wBizManager screens: rules
that span several components ("adding new data never opens a whole page"). It is shown in
Storybook under **UI Rules**.

- Edit it on GitHub (pencil icon) or locally. Keep each rule short, numbered and testable.
- **Part A** holds agreed rules. **Part B** holds proposals waiting for design to vet. When a proposal
  is accepted, move it to Part A (and update the matching Instruction Note); when rejected, delete it.
- Component-specific how-tos live in `../instruction-notes/`.
