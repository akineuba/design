# Switch

On/off switch from the accounting settings screens (remote "Toggle" component).

## Anatomy
51×31 track, `success` when on and `switch-off` when off, with a 27px white knob and a soft shadow. Optional label and description to the right.

## States
On, off, disabled on, disabled off. Exposes `role="switch"` and `aria-checked`.

## Usage
Use for settings that take effect immediately. Inside forms that are saved later, use a checkbox.
