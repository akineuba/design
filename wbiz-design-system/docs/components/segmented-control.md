# SegmentedControl

Single-choice toggles from the new features screens.

## Appearances
`pill`: rounded `surface-track` track with a primary pill for the selected option (Inventory / Free Text on line items). `boxed`: bordered 34px group with a primary selected segment and optional icons (List / Card view).

## States
Selected, unselected, hover (derived), disabled option. Arrow keys move the selection.

## Usage
Use for two to four mutually exclusive options that switch immediately.
