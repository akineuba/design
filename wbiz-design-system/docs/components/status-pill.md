# StatusPill

Status labels for table rows and record headers. Pick the tone by meaning: see `instruction-notes/status-pill.md`.

## Tones
`warning` Pending Approval · `info` Ready for Issue · `neutral` Partially Issued · `success` Completed · `error` Rejected/Cancelled (derived).

## Anatomy
22px tall, 10px horizontal padding, 6px radius, Roboto Semibold 12 on a tinted fill of the same hue.

## Accessibility
All tones are below 4.5:1 contrast (see colour docs). The label text must name the status; never rely on colour alone.
