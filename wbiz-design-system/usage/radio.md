## When to use
Choosing exactly one of 2–5 options that should all be visible, e.g. Customer Type (Individual / Business).

## When not to use
- More than 5 options → `Select`.
- A single on/off choice → `Checkbox`. (Figma shows a lone radio for "Mark as Contra"; code uses a checkbox because a lone radio can't be turned off.)

## Content
Put the question in the group label ("Customer Type:") and keep option labels to one or two words.
