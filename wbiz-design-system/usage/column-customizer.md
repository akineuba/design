## When to use
Let users choose which columns a table shows, plus report options (Include Inactive Accounts, Hide Zero-Balance Accounts, Show Subtotals).

## Choosing the trigger
| Trigger | Use it when |
|---|---|
| Primary "Customize Columns" | Report pages, where it is the main toolbar action (Trial balance). |
| Secondary or icon-only | List pages that already have a primary "Add New". |

## Rules
- Lock the column that identifies the record (Account name, Name). Users can't hide it.
- Changes apply only on **Apply**; Cancel, Escape or clicking outside discard them.
- Remember the user's choice per table (store it with the user's preferences).
