## When to use
The kebab (⋮) at the end of a table row, holding actions for that one record.

## Order and colour
Order: **View**, **Edit**, **Delete**, then related actions. Colours follow meaning:

| Tone | Use for |
|---|---|
| `view` grey | View |
| `edit` amber | Edit |
| `delete` red | Delete, Deactivate, Void |
| `link` blue | Go to related records (Transactions, History) |
| `positive` green | Money in or approval (Receive Payment, Approve) |

## Do and don't
- **Do** keep it to 2–6 items; hide (don't disable) actions the user can never take on that record.
- **Don't** put the page's main action (Add New) in a row menu.
