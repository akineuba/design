## When to use
Short, focused tasks that block the page: confirm a delete, add a tax deduction, pick a value.

## When not to use
Creating or editing a whole record → `SidePanel`. Information the user should keep visible → inline content.

## Content
- Title states the action as a question or task: "Clear all lines?", "Tax Deduction".
- Destructive confirmations name what will happen and whether it can be undone.
- Footer: Cancel (outline or secondary) then the primary or destructive action.
