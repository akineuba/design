Dropdown for choosing one value from a list. Every Select is **searchable** (UI rule 1); switch it off only for a few fixed options.

For record lists (clients, insurers, account officers) add `onAddNew`. It shows **Add New** at the bottom; open a quick-add Modal, and on save add the option and select it so the user carries on (see the *Add New Without Leaving* story).

Keyboard: ↓ or Enter opens, arrows move, Enter picks, Escape closes.
