## When to use
Status of a record: Active, Inactive, Scheduled, Sent, Failed, Draft. Also field metadata (Existing / Custom, New / Edited, Active / Archived).

## Choosing a tone
| Tone | Means |
|---|---|
| success | Active, sent, connected, published |
| warning | Pending, scheduled, needs attention |
| danger | Failed, error |
| info | Informational, scheduled post |
| neutral | Draft, inactive, archived |
| brand | Highlight (New) |

## Don't
Colour plain text to show status; always use a Badge.
