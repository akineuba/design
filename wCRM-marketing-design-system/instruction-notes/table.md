## When to use
Lists of records on desktop. On mobile, show the same records as stacked cards.

## Anatomy
`TableCard` (toolbar → table → pagination footer). Header cells are uppercase overline text on a subtle background.

## States
Default, hover, selected row, sortable header, loading skeleton, empty / no results, expandable row, compact density.

## Content
Name column first and bold; status as a Badge; row actions last, right-aligned. Numbers right-aligned with tabular figures.
