## When to use
Switching between subsets of the same page (settings sections, status sub-tabs). Not for actions.

## Choosing a variant
| Variant | Use it when |
|---|---|
| `underline` | Page-level sections (Settings). |
| `pill` | Mobile list filters. |
| `dot` | Status sub-tabs above a table (All / Drafts / Scheduled / Sent), each with its status colour. |

## How it behaves
Arrow keys move between tabs; the active tab has the red underline. Counts sit after the label.
