## When to use
| Pattern | Use it when |
|---|---|
| `RowActionsMenu` ("…") | Most tables: View / Edit / Delete in a context menu. |
| `RowActionLink` ("👁 View") | Tables whose only row action is opening the record (Campaigns). |
| `RowActionButtons` | One or two frequent actions shown inline (edit, delete); can reveal on hover. |

## How it behaves
The "…" trigger is named "Actions for {record}" for screen readers. Delete is always last and red.
